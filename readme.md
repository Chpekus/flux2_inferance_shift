## Для настройки окружения 
Создайте и активируйте конду:

`conda env create -f environment.yml`
`conda activate flux2`

## Установка PyTorch
Для torch узнайте версию, подходящую под вашу сборку https://pytorch.org/get-started/locally/
В проекте использовалась следующая версии торча. Замените xxx на версию cuda для своей сборки: 

`pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cuxxx`

## Настройка Jupyter Notebook
Для использования conda в jupiter notebook вероятно нужно выбрать его в процессе выбора окружения, 
если нет среди предложенных, регаем этой командой

`python -m ipykernel install --user --name flux2 --display-name "Python (flux2)"`

## Использование
В директорию input загружаем картинки, которые будем редачить
В файл images.txt пишем имена файлов с картинками, которые требеуется отредачить и дальше
А) old|new. Тогда заменяется строка old на строку new с промтом 
B) old|. Стирание строки old с картинки
С) |. Если ничего не указывать - очистка от всех букв/цифр на картинке

## Пример:
resp.png|РЕСПУБЛИКА|RESPUBLICA - Замена РЕСПУБЛИКА на RESPUBLICA
kir.png|Кириенко| - Очистка строки с картинки. 
Если нужно убрать не все символы с картинки - то получалось такого добиться,
Только если таргентный текст был на другой строке, а не вместе с другим текстом.
